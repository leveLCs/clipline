# Clipline 自製標記編輯器

使用者要求以 TrarrenShot 1.5.3 的功能與介面取代長按後的系統標記。依據使用者提供的工具列截圖與本機版本說明；範圍為既有圖片標記，不包含另建截圖引擎、錄影、Live Canvas。

深色背景、白色圖片裁切框和八個手柄；圖下圓角橫向工具列，藍色選取底、下方獨立深色參數面板。工具順序：矩形、圓、直線、箭頭、文字/文字氣泡、筆、螢光筆、馬賽克、放大鏡、步驟、貼圖、聚光燈、備註、OCR、復原/重做、橡皮擦、清除、分享、儲存、複製、關閉；側邊尺寸、設定、完成回存掛圖。

全部工具可用：矩形方角/圓角/虛線/填滿；箭頭開放/強調；字型/大小/顏色、氣泡背景；筆寬度/顏色；像素/模糊/實色馬賽克；放大倍率和來源連結；步驟顏色大小自動重編；Emoji 貼圖搜尋；Spotlight 形狀圓角深淺且重疊為聯集；備註七種框/箭頭樣式和可編輯總覽，輸出附註記。

選取/移動/八向縮放/複製/刪除，Shift 約束、中文 NSTextView、完整復原重做、裁切尺寸/比例預設、工具列大小/排序/顯示和工具設定記憶。OCR 重用 Vision/Option ddddocr；QR 本機 Vision 偵測可關閉提示、複製結果，不自動開啟網址。

純 AppKit/CoreGraphics/CoreImage/ImageIO/Vision，macOS 14，無新套件或商業程式/圖示複製。原入口 Markup.shared.edit(URL)/onSaved 保留，OCR/快捷鍵/影片 Trim 保留。原圖像素左上座標、EXIF 已正規化，共用內容渲染；選框不輸出，原解析度及色彩空間保留。

Session 內物件可編輯，存檔後扁平化同原系統 Markup。取消不寫入。關閉/切換圖片/退出共用未儲存提示。保存前檢查來源身分/版本，消失或被外部改寫就拒絕；原子寫入，成功才呼叫 onSaved。多頁/動畫或不支援編碼不得直接覆寫，只能另存 PNG。複製/分享僅渲染結果，不能附原檔 URL。

驗收包含模型/渲染/資料安全 assert 檢查和實機編輯視窗、中文、選取、輸出，再跑既有 OCR 11 檢查、字串、universal build/codesign。不能把編譯通過說成 UI 一模一樣。
