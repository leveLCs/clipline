# 可繼續編輯的標記回存

需求：完成回存並關閉後，再打開同一圖片，箭頭、線、文字及其他標記仍可移動、縮放、改樣式或刪除，裁切可繼續調整。

內部設計審查採用本機私有文件與圖片 UUID xattr。每次回存先保存新的不可變 JSON（版本、正規化原圖 PNG、完整 AnnotationState、輸出 SHA256），再把只含 UUID 的 xattr 寫入暫存圖片，沿用既有 RENAME_SWAP 防衝突替換。記錄存在 Application Support/Clipline/Annotations，目錄 0700、文件 0600。圖片雜湊只用於驗證，不作文件身份，避免相同平面圖對應不同原圖或隱藏元素。

重新開啟恢復 source/state/savedState，Undo 歷史從新工作階段開始。缺少本機資料或外部圖片變更，開啟平面圖並顯示狀態提示；損壞或不支援的資料拒絕開啟，避免靜默覆蓋。回存若無法保存資料或 xattr，原圖不變、編輯器保留。既有分享、複製、另存只輸出平面圖片，不附帶原圖或可移除遮罩。

Finder 保留 xattr 的移動、改名與複製可繼續編輯；各次回存採新 UUID，複本不互相覆蓋。沒有 xattr 的傳輸或另一台 Mac 僅保留平面圖。舊版已平面化內容無法還原。為支援複本與垃圾桶還原，初版不自動清除 archive；刪除圖片不會清除本機未遮罩原圖。這是使用者需要知道的儲存限制。

影響範圍：AnnotationDocument、獨立 archive 實作、FileVersion 同 fd 讀取 xattr、Markup 狀態提示、Renderer 驗證重用、語系、測試與 harness 編譯清單、README、更新保護契約。繪圖操作與分享格式不改。

驗證順序：先重現回存重開失去元素；實作磁碟 roundtrip 與失敗保護；測試相同畫面不同 state、複本、改名、外部修改、損壞、缺失、PNG/JPEG/P3/透明度、裁切/備註；原生操作回存重開並再次移動縮放；獨立審查；全套測試與固定簽章建置；正常退出舊 App，備份、安裝、重啟並確認版本與簽章；提交推送。
