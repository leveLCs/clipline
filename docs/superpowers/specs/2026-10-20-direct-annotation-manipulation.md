# 依元素類型直接調整標記

參考使用者提供的 TrarrenShot 橢圓與箭頭截圖。目標：游標在可操作元素上為手掌，第一次按下拖曳即移動，不需先選取。繪圖工具一致適用，裁切／橡皮擦保留專屬模式；空心框內仍可建立新圖形。文字／泡泡／備註雙擊編輯。命中優先序為 X、選取控制點、最上層元素、空白建立，hover 與 mouseDown 使用同一判定。

元素取消矩形虛線外框，控制點改固定畫面大小藍色圓點與白邊，增加可存取的原生 X 刪除按鈕（放開仍在按鈕內才刪除）。線／箭頭／箭頭備註使用兩端點；矩形／橢圓／遮罩／聚光燈／文字框／框形備註使用八點。泡泡另保留尾端，放大鏡另保留未連動取樣點。步驟／圖章用四角等比縮放；步驟框以實際 style.size 計算。筆畫／螢光筆用可見筆跡範圍四角等比縮放 points 與線寬，單點與水平／垂直筆跡也有可操作範圍。裁切控制點維持原樣。

僅調整幾何與互動，不新增旋轉／曲率／逐筆節點工具，不改 archive 格式。文字框控制點改框尺寸，字級使用現有屬性。hover／短點不寫入復原歷史；一次拖曳只提交一次，Esc 取消預覽，X 可復原。修正原有 metadata 容許、固定簽章與本機可編輯回存均須保留。

影響：AnnotationCanvas 命中、游標與控制點／刪除 UI；AnnotationDocument 筆跡可見範圍；行為測試、原生 QA、README、更新驗收契約、版本。內部設計審查已完成；筆跡採四角等比以一併處理退化範圍與線寬一致。
